# OVERSEAS — Abrokyire Aba Ghana

A streetwear e-commerce storefront built from the customer's supplied OVERSEAS reference.

## Current build

- Next.js App Router + TypeScript
- Responsive black/cream editorial storefront
- Hero campaign section
- Product collections and product detail pages
- Story / Foreign Boys Clan section
- Lookbook and contact pages
- Ghanaian pricing in GHS
- Mobile navigation
- Initial add-to-bag interaction
- Development imagery currently uses remote Unsplash placeholders

## Run locally

```bash
npm install
npm run dev
```

## Next production phases

1. Replace placeholder imagery with the customer's approved OVERSEAS assets.
2. Connect Supabase for products, inventory, customers and orders.
3. Add Ghana payment and shipping integrations.
4. Add persistent cart and checkout.
5. Add admin inventory and order management.
6. Add transactional emails and order tracking.

The visual direction intentionally follows the supplied reference: strong black/white contrast, oversized typography, editorial photography, compact navigation, collection cards, community storytelling and a Ghana-first streetwear identity.
